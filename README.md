# Pro Web Design Order Note Templates for WooCommerce

Save and reuse order note templates in the WooCommerce admin. Works with HPOS and WooCommerce Subscriptions.

If your shop sends the same kinds of order notes again and again — dispatch confirmations, delay
apologies, payment chasers — this plugin lets you store them once and insert them in one click,
instead of retyping them on every order.

## Features

- Reusable note templates, inserted into the order notes box in one click
- Placeholders for order details, filled in automatically
- Choose whether a note is private or sent to the customer
- Works with WooCommerce High-Performance Order Storage (HPOS)
- Works with WooCommerce Subscriptions

## Installing

Install from the WordPress plugin directory — search for "Pro Web Design Order Note Templates",
or download it here:

**https://wordpress.org/plugins/pro-web-design-order-note-templates-for-woocommerce/**

Requires WordPress 5.8 or newer, PHP 7.4 or newer, and WooCommerce.
